LIMITACIÓN DEL ENTORNO DE REVISIÓN
----------------------------------
Este entorno no tuvo acceso al registro npm, por lo que no fue posible ejecutar
una instalación limpia real de dependencias ni `npm run build`/`npm run lint`
con los paquetes del proyecto. Por esa razón no se incluye un package-lock.json
stale. En un computador con Internet, el primer paso debe ser `npm install`,
seguido de `npm run lint` y `npm run build`.

Tampoco se recibió un dump/esquema SQL ni las políticas actuales de la base de
Supabase. Las migraciones deben probarse primero en staging/copia antes de
aplicarlas a producción, tal como se explica en README.md y SECURITY.md.
